Game_Engine - README
====================

This project is a simple 2D game engine in C++ from scratch. It's a fun way for me to train and keep learning C++.

For now, it implements:
  - A basic ECS (Entity Component System) type structure.
  - A small portion of the map is displayed, using a tile set.
  - You can move your character with ZQSD, without any animation yet.
  - Collision with the other character is detected and changes size of your character. Collision with map not implemented yet.
  - Number of frames per second is displayed on the consol every second and stays ~60fps.

Next goals would be:
  - Implement the whole map, with collisions.
  - Parse map from file (currently hard coded).
  - Add animations.
